ReCut for Mac
=============

START
  1. Double-click "ReCut.command".
     The first time, macOS may say it can't verify the developer:
     right-click ReCut.command → Open → Open. (Only needed once.)
  2. Your browser opens ReCut. Keep the small Terminal window open while you work.
  3. First time only: paste your Anthropic and ElevenLabs API keys in Settings.

NEEDS
  Node.js 20 or newer (free): https://nodejs.org → LTS. ReCut opens that page for you if it's missing.

WHERE THINGS ARE
  Projects:  your Movies folder → ReCut
  API keys:  app/.env (stays on this Mac)

QUIT
  Close the Terminal window.
